**RULE #1 (NON-NEGOTIABLE): EVERY slide/page MUST show BOTH the Danantara Indonesia logo (top-left) AND the PLN Icon Plus logo (top-right).** Use the CSS classes — the logo images are embedded in styles.css, so they render in any consuming project. Do NOT use `<img src="assets/...">`: the assets/ folder is NOT copied into consuming projects and will render blank. Snippet (light ground; copy verbatim onto every slide):
`<div class="pln-logo-danantara" role="img" aria-label="Danantara Indonesia" style="position:absolute;left:72px;top:32px;width:190px;height:46px;z-index:5"></div><div class="pln-logo-pln" role="img" aria-label="PLN Icon Plus" style="position:absolute;right:72px;top:28px;width:150px;height:54px;background-position:right center;z-index:5"></div>`
Dark/photo ground: `pln-logo-danantara-white` + `pln-logo-pln-white`. Cover/closing may use the combined lockup class `pln-logo-color` / `pln-logo-white`. React: `<BrandLogos tone="light|dark" />`. Logo elements need explicit width and height. Before finishing, check every slide has both logos — an output missing either is wrong. Same for imagery: use `pln-photo-*`, `pln-hdr-art--*`, `pln-bg-*` classes, never assets/ paths.

**RULE #2: structure, colour and components are chosen separately.** Before building, ask the user (ask_user form; use defaults if they skip): (1) purpose → structure template V1–V9; (2) colour theme: `korporat` (default) | `royal-emas` | `teal-blueprint` | `navy-eksekutif` | `biru-digital` | `asli`; (3) canvas 1280×720 / HD 1920×1080 / A4; (4) dominant background light/mixed/dark; (5) density; (6) imagery (photo / header-art theme / Indonesia map / none); (7) icon style (line / 3D / mixed); (8) font `arial` | `arial-calibri`; (9) key components; (10) output HTML/PPTX/PDF. Apply the theme with `<html data-pln-theme="…" data-pln-font="…">`; in new markup use role tokens `var(--t-primary|strong|dark|dark-2|secondary|flow|signal|highlight|tint|line)` instead of brand hex. Templates fix only the MINIMUM STRUCTURE (section order, slide zones, canvas) — never the component types or the palette. Any template works with all 5 palettes, and any component from any family (blocks, slide, hd, commercial, data) may fill its content zones; all follow the active theme. See readme "Cara memakai" for themes, recipes and the need→component map.

**MANDATORY RULE:** every output built with this system (each slide, page, dashboard, document, poster) must always show BOTH the Danantara Indonesia logo and the PLN Icon Plus logo — Danantara top-left, PLN Icon Plus top-right (or side-by-side lockup on cover/closing).
