# Font

- **Arial** — font utama (judul selalu Arial). Font sistem, tidak perlu file.
- **Calibri** — dipakai untuk isi template V7. `tokens/fonts.css` mencari file berikut di folder ini:
  `Calibri-Light.ttf`, `Calibri-LightItalic.ttf`, `Calibri-Regular.ttf`, `Calibri-Italic.ttf`, `Calibri-Bold.ttf`, `Calibri-BoldItalic.ttf`.

Calibri adalah font berlisensi Microsoft dan **tidak disertakan** di repository. Salin dari instalasi Microsoft Office/Windows yang berlisensi bila diperlukan; tanpa file tersebut browser memakai Calibri lokal (jika terpasang) atau fallback sans-serif.
